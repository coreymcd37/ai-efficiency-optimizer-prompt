# Security Policy

This project is a set of written instructions, not software, so there's no code to exploit. Security still matters, though, because the guide gives advice about handling data, credentials, and automation.

## Reporting a problem

If you find advice in the guide that could lead someone to leak data, expose credentials, or run something unsafe, please report it privately through [GitHub's private vulnerability reporting](https://github.com/coreymcd37/ai-efficiency-optimizer-prompt/security/advisories/new) instead of opening a public issue.

Please include the section, what could go wrong, and a suggested fix if you have one. I'll reply as soon as I can.

## Supported versions

Only the latest version on the `main` branch is maintained.
